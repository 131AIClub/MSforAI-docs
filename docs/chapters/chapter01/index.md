# 数学基础

在本章节，我们将介绍学习深度学习所需要掌握的一些基本数学知识：
- **线性代数**：组织与表示大量数据、运算的基础方式。
- **多元微分**：对大量自变量和大量因变量的函数进行微分，使用朴素的逐个分析方法会带来很大的心智负担。因此有必要讲解基础的多元微分方法。
- **梯度下降法**：这是深度学习最基本的优化方法之一。
- **线性回归**：这是线性代数、多元微分、梯度下降法的综合应用，顺便通过这个场景来认识统计学习的基本pipeline。
