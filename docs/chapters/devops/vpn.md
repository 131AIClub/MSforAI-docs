# 爱的魔法

这一章排在技术基础的最前面，原因很实际：后面几乎每一章都会撞上它。

`pip install` 卡在 0%、`git clone` 到一半断掉、想看的官方文档打不开、想注册的服务连页面都加载不出来——这些都不是你的电脑坏了，也不是教程写错了。你只是撞上了一道你没法绕过去装作不存在的墙。

> [!CAUTION] 先把边界说清楚
> 我国现行法规（《计算机信息网络国际联网管理暂行规定》第六条）要求，接入网络进行国际联网必须使用国家公用电信网提供的国际出入口信道。也就是说，自行搭建或使用其他信道跨境联网，在合规上是有问题的；有些学校的校园网管理规定也另有约束。
>
> 所以这一章的定位很明确：**帮你拿到学习和研究需要的技术资料**。请优先走学校、实验室、图书馆已经提供的正规通道；下面讲到的东西，请你自己判断要不要用、用来干什么。**不要转卖、不要分享给不认识的人、不要拿它去做别的事。**



## 代理是怎么绕过去的

思路其实特别朴素：**既然你不能直接和目标站点说话，那就找一个能和它说话的中间人，然后你和中间人之间的对话别让人看懂。**

<ThemedImage src="/static/vpn/proxy.svg" dark="/static/vpn/proxy-dark.svg" alt="代理原理示意图：不开代理时直连境外被拦下；开了代理后流量经加密隧道穿过审查设备到达境外节点，再由节点访问目标站点；国内流量则按规则直连" />

图上有三条线，对应三种情况：

**① 不开代理。** 请求直接往外走，到墙那里就被拦下——表现就是开头说的那些：连不上、一直转圈、或者传到一半断掉。

**② 开了代理。** 你的请求先交给一个**跑在你自己电脑上的程序**——代理客户端。它把请求用加密协议包好，发给一台在墙外的服务器（**节点**）；节点拆开包，用它自己的身份去访问目标站点，再把结果原路带回来。

这里有两个关键点值得单独强调：

- **客户端在你自己的机器上。** 它不是网页，不是插件，是一个常驻的程序。它没开着，一切都不生效——这是新手最常见的"明明配好了却不通"。
- **墙看到的只是一条到某个境外 IP 的加密连接。** 它不知道你在访问什么，因为那一层已经被包在里面了。这就是"隧道"这个说法的来源。

**③ 国内流量按规则直连。** 这条线很容易被忽略，但它是体验好坏的关键：访问 B 站、知乎、国内镜像源的时候，没有任何理由绕地球一圈。所以客户端会拿一份规则表（哪些域名、哪些 IP 段属于国内）逐个请求判断：**这个走隧道，那个直连。**

这就是客户端里那个下拉框的含义：

| 模式 | 行为 | 什么时候用 |
| --- | --- | --- |
| **规则**（Rule） | 境外走隧道，国内直连 | **默认就用这个**，日常唯一需要的模式 |
| **全局**（Global） | 所有流量都塞进隧道 | 规则表把某个站点判断错了，临时救急 |
| **直连**（Direct） | 全部直连，等于没开 | 排查问题时用来对照 |

很多人上手第一件事是开全局，然后抱怨"开了之后什么都变慢了"——国内网站被你送去绕了一圈地球，当然慢。

## 三条路子，代价各不相同

| 路子 | 成本 | 门槛 | 你要承担的 |
| --- | --- | --- | --- |
| **学校 / 实验室提供的通道** | 通常免费 | 问管理员或师兄师姐 | **最正规，优先考虑。** 缺点是往往只能访问指定的学术资源 |
| **付费订阅** | 每月几块到几十块 | 最低，导入一条链接就能用 | 服务商随时可能跑路或被封；你的**全部流量都经过它的服务器** |
| **自己租境外服务器搭** | 服务器一年几十到几百 | 要会用命令行，还要能付境外服务器的钱 | IP 被封了自己换、出问题自己修，但至少你知道对面是谁 |
| **别人分享的免费节点** | 0 | 最低 | **最不建议。** 你完全不知道谁在运营它、它在记录什么。免费的东西是最贵的 |

不做任何具体推荐——这类服务的保质期实在太短，写下来的第二个月就可能不准了。给几条不会过时的判断标准：

- **能不能按月付？** 一上来就只卖年付、两年付的，跑路成本对它来说太低了。
- **价格是不是低到不合理？** 服务器和带宽都是真金白银，低于成本的价格意味着钱要从别的地方赚回来——比如你的流量。但是也不会太贵，那是智商税。
- **有没有稳定的联系渠道？** 只有一个随时能解散的群，出问题你找不到人。

> [!WARNING] 有一件事和你选哪条路无关
> **凡是经过别人服务器的流量，别人技术上都有能力看见。** 加密只保证墙看不见，不保证中间人看不见——因为那个中间人正是替你解密的人。
>
> 所以有两类东西不要在来路不明的通道上过：**你的身份凭据**（学校统一身份、网银、私钥），以及**不属于你的东西**（实验室数据、实习公司的代码）。这句话在 [AI 辅助编程](./vibe-coding.md) 讲中转站时还会再说一遍。

## 上手：从零到能上网

### 装一个客户端

现在主流的客户端基本分两个生态，**功能上没有本质区别，挑一个界面顺眼的就行**：

| 生态 | 特点 |
| --- | --- |
| **Clash / Mihomo 系**（Clash Verge Rev、Mihomo Party、FlClash 等） | 用得最多，几乎所有订阅都兼容它的配置格式；规则分流的生态最成熟 |
| **sing-box 系** | 更新的一代，配置更统一，跨平台一致性好 |

由于 Clash 的图标是一只猫，所以我们有如下 meme：

![clash](/static/vpn/clashmeme.png)

选的时候注意两件事：**从项目的官方仓库或官网下载**（这类软件是搜索引擎里投毒的重灾区，山寨版塞后门的事发生过不止一次），以及**别装那种和某个服务商绑死、只能用它自己订阅的定制客户端**。

我们将会使用 Windows 11 操作系统做示范，下载的客户端为 [FlClash](https://flclash.cc/)，这是一个开源项目，相对安全。

可以在下载页面找到[镜像地址](https://dl.p6p.net/FlClash/)，这样我们就可以在没有开代理的情况下下载一个代理软件 :laughing:

### 注册机场并购买套餐

![某个机场后台的「下载和教程」页面，列出各平台客户端与配置说明](/static/vpn/airport.png)

「机场」是卖节点订阅的服务商的通称，你在别人的教程里基本只会看到这个说法。一般机场的页面都大同小异，基本上都很一目了然。

购买套餐时，建议一开始的时候先买一个便宜的套餐试一试水。一般机场的套餐有按月的和长期有效的，我个人会倾向于购买那个最贵的长期有效的，因为一个月基本上用不完额度，剩下的都浪费了。

在续费的时候需要小心，有时候续费会覆盖前一次购买的套餐（即使额度还没有用完）。

参考价格：按月支付差不多一个月 10 元，不限时套餐平均每块钱能够购买的流量应该超过 6G。

比如下面这个套餐，38.80 买 260G，均价约 6.7G 每块钱，就属于还算合理的档：

<ThemedImage src="/static/vpn/plan-card.svg" dark="/static/vpn/plan-card-dark.svg" alt="机场套餐卡片示例：巨量不限时流量包，包含流量 260 GB，标价 38.80 元，最多支持 3 个设备同时在线" />

卡片上的黑话顺便解释两个：**「不限时」**是说这 260G 不按月清零，用完为止——所以它更像买了一块额度，而不是包月；**「x 个设备同时在线」**是个真的限制，电脑和手机都要用的话别买最低那档。至于「解锁当地热门平台」说的是流媒体，和写代码没什么关系。

### 导入订阅

你付钱之后，机场会提供一个订阅链接，你需要把它导入到你的 FlClash 里面。

![FlClash 的「配置」页面，左下角有一个用来添加订阅的加号按钮](/static/vpn/flclash.png)

> [!CAUTION] 订阅链接就是你的账号密码
> 它不需要密码就能用。**发给别人 = 把账号给别人；截图发群里 = 发给了所有人。** 求助的时候记得打码，包括链接里那一长串看起来没意义的字符。

点击左下角的 + 号，选择 “URL”，把链接粘贴进去就行。

不出所料，过一段时间后上面就会多一个方块，代表你刚刚导入的机场。

### 打开开关

现在我们可以点击侧边栏的“代理”，选择一个节点，点击“延迟测试”之后可以查看节点的延迟，随便选择一个绿色的节点。

然后再点击侧边栏的“仪表盘”：

![FlClash 的仪表盘页面，可以切换分流模式、开启系统代理和总开关](/static/vpn/dashboard.png)

然后把模式选成**规则**，点击“系统代理”并按下右下角的按钮，恭喜！你现在可以访问 google.com 等网站了。

如果打不开，先不要怀疑机场跑路了——按这个顺序查一遍，九成的问题在前三条里：

1. **客户端还开着吗？** 它是一个常驻程序，窗口关掉、开机没自启、被安全软件拦掉，都会让一切配置瞬间失效。这是最常见的一条。
2. **模式是不是变成了「直连」？** 直连等于没开。顺手确认右下角那个总开关也是打开的。
3. **选中的节点还活着吗？** 回「代理」页面重测一次延迟，红色或者超时的节点换掉。单个节点挂掉是常事。
4. **浏览器里有没有别的代理插件？** 那类插件会覆盖系统设置，自己抢着接管流量。有的话先禁用掉再试。
5. **订阅是不是过期或者流量用完了？** 回机场后台看剩余额度和到期时间。

排查的时候有个很省事的对照办法：把模式切成**全局**试一次。全局能通、规则不通，说明是规则表把那个站点判断成国内了；两个都不通，问题在上面那五条里，跟分流没关系。

> [!TIP] TUN 模式是什么
> 客户端里通常还有一个叫 **TUN**（或"虚拟网卡""增强模式"）的开关。系统代理只能影响那些主动去读系统设置的程序，而 TUN 是在系统里插一张虚拟网卡，把**所有**流量都接过来，不管程序愿不愿意配合。
>
> 它的好处是命令行、游戏、各种不认系统代理的程序都能一起生效；代价是要管理员权限，偶尔会和 VPN、虚拟机、某些安全软件打架（包括学校的 VPN 客户端）。日常使用的话，只开系统代理就够了。

### 终端里的代理要单独说一句

上面那个「系统代理」只对**愿意去读系统设置的程序**有效。浏览器都读，但你在 PowerShell 里敲的 `git`、`pip`、`curl` 大多不读——所以你会遇到一个很迷惑的现象：**浏览器能打开 GitHub，`git clone` 还是断在半路。** 这不是配错了，而是它根本不知道代理的存在。

而这恰恰是后面几章最常撞墙的地方（[Git 与 GitHub](./git/index.md)、装包、拉模型权重）。两条解法：

**省事的那条**是把上面那个 TUN 打开，终端自动跟着走，什么都不用配。

**不想开 TUN 的话**，就在终端里临时告诉它代理在哪：（怎么打开终端见下一节）

```powershell
$env:HTTP_PROXY  = "http://127.0.0.1:7890"
$env:HTTPS_PROXY = "http://127.0.0.1:7890"
```

`7890` 是 Clash 系客户端的传统默认端口，但**以你客户端里实际显示的那个为准**，FlClash 的仪表盘上能看到。

这两行只对**当前这个终端窗口**有效，关掉就没了。这其实是好事：需要走代理的时候设一下，装国内镜像源的包时开个新窗口，互不干扰。

Git 还有一套自己的代理配置，如果只是它不通，可以单独给它设：

```powershell
git config --global http.proxy http://127.0.0.1:7890
```

不用的时候记得撤掉，不然代理关了之后 Git 会一直去连一个不存在的端口：

```powershell
git config --global --unset http.proxy
```

## 你是不是真的需要它

新手最容易犯的一个错，是把"我访问不了 X"直接翻译成"我需要一个魔法"。**实际上你遇到的问题里有一大半有更省事、更稳、也更合规的解法。**

| 你想干的事                   | 先试这个                                                     |
| ---------------------------- | ------------------------------------------------------------ |
| `pip` / `conda` 装包慢或超时 | 换国内镜像源（清华 TUNA、阿里云等），通常比走代理还快        |
| `npm` / `yarn` 装依赖        | 换 `registry.npmmirror.com`                                  |
| 下载模型权重、数据集         | HuggingFace 的国内镜像（设一个 `HF_ENDPOINT` 环境变量就行）  |
| 从 GitHub 拿代码             | 很多时候直连是通的，只是慢；也可以用学校镜像站，或把仓库导入 Gitee 再拉 |
| 查论文、下 PDF               | 学校图书馆的 WebVPN / 校内数据库；很多论文作者主页上就挂着免费 PDF |
| 看官方文档                   | 大部分文档站国内能直连，先试一下再说                         |

这些办法的共同点是：**不需要你把全部流量交给一个陌生人，也不需要你每次上机先检查节点还活着没有。**真正绕不开的场景大概是这些：注册和登录只在境外提供服务的平台、需要境外 IP 才能调用的 API、以及一些没有任何镜像的站点。
