# 技术基础

在本章节，我们将介绍一些比较基础但是学校又不太可能教的技术：
- **爱的魔法**：计算机技术的学习经常需要访问在国内网络环境下受限的站点，因此我们需要一些魔法。
- **终端与命令行**：终端与命令行是许多工具的一等公民，熟悉终端与命令行可以帮助我们更好地理解和上手许多的工具。
- **Visual Studio Code**：一个开放、轻量级的代码编辑器，通过插件可以搭建强大的集成开发环境。
- **Git 与 GitHub**：管理与分享项目代码的工具与平台，~~顺便还可以交友~~。
- **AI 辅助编程**：介绍主流的 Vibe Coding 工具与模型，以及 Vibe Coding 的一些小tip。
- **SSH 远程登录**：在远程机器上开发几乎是不可避免的。无论是组里的服务器还是自己的服务器，甚至是 WSL。
- **WSL** ：Windows Subsystem for Linux，在 windows 上方便地跑一个 linux。
